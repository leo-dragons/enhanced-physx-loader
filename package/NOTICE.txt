Enhanced PhysX Loader - notices

This package contains only original code. It does not contain, and must not be
distributed together with, any NVIDIA PhysX binaries, SDK headers or SDK code,
or any file from Mirror's Edge. At runtime it loads the PhysX files that ship
with the user's own copy of the game.

Interface layouts (virtual function table orders, structure offsets, enum
values) were determined by inspecting the game's PhysX 2.8.0 runtime and by
reference to the publicly documented PhysX 2.8 API, for the purpose of
interoperability.
